Assembly Line 2 Mobile Version DevLog #2 September 12, 2024

Improvements to the Editing tool

Following up on the previous mobile version DevLog, I've been working on improving the editing tool and the whole editing flow. I've been experimenting with different ways to improve it and would like to present the current state of it. Note that the UI is just a placeholder to test different things quickly, it will change when the update is finally released.

The improvements made make the tool pretty close to how the desktop version editing tool works, you have a Build tool, a select tool, and a rotate/delete tool to quickly delete or rotate a single machine. Now, the big improvement comes in the select tool. You will finally be able to box-select machines to quickly select the machines you wish to edit. To differentiate between a camera drag, or a box selection, when inside the select tool, you will use two-finger drag to move the camera around, and one-finger drag to box-select, in my own testing this order was best, but i want to hear your opinion, if you would prefer the other way around.

Previously, when selecting machines to copy or move, if you selected them, let's say, to move, and instead you wanted to copy, you had to re-select them all over again with the copy tool. Now, they act more independently. After selecting, you can choose to copy, or move.

As you may see in the previous video, the moving of machines now works a bit different as well. Now, when starting the move, the selected machines "stick" to the center of the screen, and by moving the camera, you move the machines. This makes it easier for the new features to come in, one of these that is currently implemented is the ability to rotate all the machines being moved.

There is still more work to be done to this since it is being done from scratch, but I believe that is in a good direction. I want to hear your opinions on this, do you think that the changes made are positive, and do you think the controls would feel good?
