Assembly Line 2 Mobile Version DevLog #1 August 11, 2024

What's Next

With the focus on the development Desktop version, the Mobile version has been a bit "neglected", which I first want to apologize for. However, since the Desktop version has been released, I can now focus on both simultaneously.

The first thing that I will now be focusing on in the Mobile version is the Editing Tool, and the whole line editing "flow". It isn't the best right now, especially if you are building large lines, and I want to improve this.

Let's give an example if you wanted to move some machines, at the moment, you have to individually select one by one, tap-and-hold the screen, and then move. If you thought that maybe you wanted to copy instead of move, you had to select them all over again. When it is only two or three machines, that's okay, but when you start making large lines with tons of machines, moving and copying become a cumbersome task.

When developing the Desktop version, I made it from the ground up, with all the knowledge and suggestions that I received from the Mobile version, and now, I want to take that into the Mobile version. As some of you already played the Desktop version, You can see that the selection of the machines, and the copying/moving are "separate", so you can select all the machines you want, and then decide if you want to copy or you want to move. Another thing is the ability to select them in an area. You can also rotate multiple machines while keeping them "grouped".

To be honest, I am not sure yet how exactly I will implement this in a Mobile environment, I have seen some suggestions, and I have begun the development of this new Editing Tool and will be testing different things to try to figure out how to best approach this.

When I have more "final" solutions, I will be sure to show them and gather feedback from the community.

I was suggested to create these types of posts, which help show the community what is going on with the development of the game and the direction it is taking and I will try to continue this on both versions of the game.

Thank you for reading and thank you for playing the game.
