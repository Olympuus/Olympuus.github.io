Assembly Line 2 Desktop Version DevLog #1 August 11, 2024

Upcoming plans

The Desktop version has been released, and I'm glad the overall feedback has been positive. Although players enjoy the game, I've received some feedback that the designs they are achieving in the Desktop version are a bit repetitive and not as efficient compared to the Mobile version. They have also been a bit of negative feedback towards my decision to not include speed upgrades to the machines other than the Starters. I have also received feedback suggesting that both these problems may be connected. My original goal with only giving upgrades to the Starters was to make the overall size of the factory bigger, and further challenge the players to find ways to route resources and distribute them to the machines. I see now that this goal wasn't quite achieved in the best way possible. So, my goal now is to take all the feedback received and find a better balance. To be honest, i am not sure yet how to achieve this, but have a few ideas. The first one, is to experiment with re-adding the upgrades back to more machines. I think I can find a good way to add them and keep the same goal of having bigger factories, but more efficient ones at the same time. The second one is to add more machines, I believe that if the player has more options for distributing the resources around, they can improve their current line. The third is to adjust the resource requirements for some blueprints, but honestly, this is my least priority, the reason being, that I think that changing blueprint requirements could break some current designs or maybe reduce the efficiency without the player having a clear vision of what happened. This are still ideas, and may or not be implemented, but let's go a bit further on some of the ideas that I have for machines that could help. The Alternator Starter would count as a normal Starter to the limit, but it would allow the Player to set a "cycle" between two (or maybe more) resources, an example would be, first, it would spawn a Diamond, then the next second a Gold. The Split-Selector, a machine that also has been suggested by some players, is a Splitter with the Selector ability to choose which resource to split while ignoring the rest. Hopefully, with some of this, I can improve the Desktop version, and give a better experience to the players. My next goal with the next update to the game is to add more ways for the players to edit their factories. To do that I want to add a new system called "Schematics". Schematics basically will let you "save" a group of machines, to later be used whenever the player wants (providing that it is still inside the money and machine limits), to build that group of machines. For example, if you have a design that produces 1 circuit/s, you can save this design and re-build it whenever you want. I also want to add shareability to this system and plan on adding a way to give the player some kind of "code", and then other players can import those designs by using that code. Let me know what you think of this, like always, I use a lot of player feedback to know what I need to improve the game on. Also, if you have been playing the Desktop version, consider leaving an honest review on the Steam page, this not only helps me by giving me an overall of how the game is being received by players, but also helps potential other players to decide whether to play the game or not.
